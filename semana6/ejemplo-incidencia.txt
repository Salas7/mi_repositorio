Ejemplo de JSON para reportar una incidencia ciudadana
=======================================================

Un ciudadano podría enviar la siguiente petición POST a http://localhost:3000/incidencia:

{
  "tipo": "Iluminación pública",
  "descripcion": "La comunidad reporta que una lámpara del parque no funciona desde hace varios días."
}

El servidor respondería con:

{
  "mensaje": "Incidencia registrada",
  "tipo": "Iluminación pública",
  "descripcion": "La comunidad reporta que una lámpara del parque no funciona desde hace varios días."
}

Otros ejemplos de incidencias que un ciudadano podría reportar:

Ejemplo 2 - Vía pública:
{
  "tipo": "Vía pública",
  "descripcion": "Hay un hueco grande en la calle principal del barrio que representa un peligro para los vehículos y peatones."
}

Ejemplo 3 - Basuras:
{
  "tipo": "Recolección de basuras",
  "descripcion": "No se ha recogido la basura en el sector desde hace tres días, generando malos olores y acumulación de residuos."
}
