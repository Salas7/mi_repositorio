CONCEPTOS BÁSICOS DE GIT
========================

Repositorio:
Un repositorio es el espacio donde Git almacena todos los archivos de un proyecto
junto con el historial completo de cambios realizados. Puede existir de forma local
en tu computador o de forma remota en plataformas como GitHub, lo que permite
colaborar con otras personas y mantener una copia segura del proyecto.

Commit:
Un commit es una instantánea o fotografía del estado del proyecto en un momento
determinado. Cada commit guarda los cambios realizados desde el commit anterior,
junto con un mensaje descriptivo y la fecha en que se realizó. Gracias a los
commits es posible revisar el historial del proyecto y revertir cambios si es
necesario.

Push:
El comando push se utiliza para enviar los commits realizados en el repositorio
local hacia el repositorio remoto (por ejemplo, GitHub). De esta manera, los
cambios quedan publicados y accesibles para otros colaboradores del proyecto o
simplemente como respaldo en la nube.
